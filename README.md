## ⚙️ Setup Instructions

### Clone the repository

```bash
git clone https://github.com/Nitinmauryaa/nitins-portfolio-page.git
cd nitins-portfolio-page
```

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm run dev
```

👉 Open: http://localhost:5173
